# CDPO-USP. Ciência de Dados e Pesquisa Operacional

Acervo pessoal de consulta do curso de **Ciência de Dados e Pesquisa Operacional (USP)**, realizado em **2025**. Este repositório reúne uma seleção organizada de materiais didáticos, notebooks, listas de exercícios, gabaritos e registros de monitoria.

> **Origem e autoria:** os materiais do curso são de autoria de seus respectivos docentes e colaboradores. Este repositório é uma cópia pessoal organizada para estudo, **não um fork oficial** nem uma publicação institucional da USP.

## Organização

| Diretório | Conteúdo |
| --- | --- |
| [`ciencia-de-dados/material/`](ciencia-de-dados/material/) | Notebooks, exercícios e gabaritos organizados por quinzena |
| [`ciencia-de-dados/aulas/`](ciencia-de-dados/aulas/) | Anotações e exemplos complementares de aulas |
| [`ciencia-de-dados/monitoria/`](ciencia-de-dados/monitoria/) | Materiais de monitoria organizados por data |
| [`pesquisa-operacional/material/`](pesquisa-operacional/material/) | Notebooks, listas e gabaritos de Pesquisa Operacional |
| [`pesquisa-operacional/aulas/`](pesquisa-operacional/aulas/) | Exemplos complementares de aulas |
| [`pesquisa-operacional/monitoria/`](pesquisa-operacional/monitoria/) | Materiais e exercícios de monitoria por data |

O notebook [**Apresentação do curso**](CDPO%20-%20Apresenta%C3%A7%C3%A3o%20do%20curso.ipynb) está na raiz do repositório.

## Utilização

- Os arquivos `.ipynb` podem ser consultados diretamente no GitHub ou abertos em um ambiente Jupyter compatível.
- Os notebooks podem depender de bibliotecas e arquivos auxiliares específicos. Consulte as instruções de cada material antes de executá-lo.
- A numeração `q1`, `q2` etc. nos nomes dos arquivos preserva a organização adotada neste acervo.

## Produção pessoal

Este repositório tem finalidade principal de **consulta e preservação de materiais do curso**. Caso sejam incluídos trabalhos autorais futuramente, serão identificados separadamente, por exemplo em `minha_producao/`, para não confundir exercícios próprios com materiais didáticos de terceiros.
